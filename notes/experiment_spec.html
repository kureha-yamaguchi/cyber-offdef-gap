Experiment spec · research study

Does removing a model's refusals also remove its ability to defend?

One model, two versions: the original and a copy with its refusal behaviour surgically ablated. Both run the same cyber benchmarks on the same hardware. We read how offence and defence scores move between them.

model pair 2 offence + 2 defence benchmarks within-pair deltas only budget cap $800

The two models

Same architecture, same chat format, same reasoning channel. The ablated copy had a single "refusal direction" projected out of its weights, which cut refusals on a harmful prompt set from 100% to 26% while barely changing behaviour on ordinary prompts.

The design: a 2×2 read through its deltas

Three outcomes we can tell apart

Each panel shows how the two axes move when going from the aligned model to the ablated one.

Uniform capability loss

Both drop by a similar relative amount. The weight edit damaged the model generally.

Targeted defensive sandbagging

Offence holds (or rises) while defence falls. This is the signature of interest.

Pure offensive uplift

Offence rises, defence unchanged. Refusals were removed and defence stayed intact.
