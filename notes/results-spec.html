Results · AuditBench defensive axis · aligned vs refusal-ablated gpt-oss-120b

Defence drops — and it's precision that collapses, not recall

Across all four attack-investigation tasks the refusal-ablated model's F1 falls. It still finds the attacks (true-positive rate flat or higher), but it stops being able to call anything benign: false positives rise 3–44×, and it never once returns "nothing suspicious here."

Scored with the upstream AuditBench metric (unchanged scoring logic, robust parser), HIGH_SUSPICIOUS threshold, 33 scenarios per task pooled across Lab and OpTC datasets, 3 attempts each. Δ = ablated − aligned.

What this means for the research question

Reading the signature

This is not sandbagging by omission. Deliberate defensive under-performance would show up as missed attacks — a lower TPR. Instead TPR is flat or higher. The ablated model is not hiding detections.
The lost capability is restraint. Removing the refusal direction appears to have removed the model's ability to decline to flag — to judge a window benign. Everything becomes suspicious, so precision and F1 collapse.
Defence-only so far. Whether this is targeted or a general degradation still needs the offence benchmarks as the capability anchor (the plan's 2×2), plus the general-capability control.

Method & caveats

How the numbers were produced

Scoring. Upstream task_computemetrics.py with its TP/FP/FN logic, entity fuzzy-matching and aggregation untouched; only the brittle positional line-parser was replaced by a JSON parser (gpt-oss emits multi-line JSON arrays the original could not read).

Unparseable findings count as no detection and are reported: 3–10% of findings per side, comparable across models. Verdict spelling (HIGH_SUSPIOUS) repaired symmetrically; date-less timestamps given the chunk's date.

Pooling. Per-task F1 is micro-averaged over Lab + OpTC and edge + raw cells (summed counts), so OpTC's large FP mass dominates. Several Lab entity cells score 0 for both models.

Parity. Identical vLLM 0.31, TP=2, 131k context, temp 0.7, seed 1234, reasoning high, prompts and scaffold. Only the weights differ.
